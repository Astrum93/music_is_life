## 2026-11-17 · 운영 데이터 uid 전환, 보안 규칙 강화, 인증·프로필·게시물 이전

실사용자 데이터를 지키면서 클린 아키텍처 전환을 시작했다. 데이터를 바꾸는 작업은 백업 → dry-run → 적용 → 검증 순서로 진행했다.

- GetX 기반 `core/` 뼈대(`Failure`, `Result`, 라우터, DI)와 인증 이전, 가입 컬렉션 이름 오류·같은 이름 가입 시 덮어쓰기 수정
- Firestore 사용자 문서 ID를 이름에서 uid로 이전하고, 친구·채팅·좋아요의 이름 참조도 uid로 변환
- Firestore·Storage 보안 규칙 강화(에뮬레이터 테스트), 메일·전화번호를 비공개 문서로 분리
- 프로필·게시물을 컨트롤러와 Repository 구조로 이전
